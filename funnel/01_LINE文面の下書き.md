# 体験会まわりのLINE文面（下書き）

2027年度・小学生向け体験会で使う文面の下書きです。
プロラインでも自作でも、そのまま使えるように書いています。

## 使い方

- 【　】の部分は、決まったら差し替えてください
- 【お子さまのお名前】など、名前を自動で入れられるかはツール次第です（未確認）
- 入れられない場合は、その部分を消しても文がつながるようにしています
- 太字や絵文字は、LINEで崩れないよう最小限にしています

## まだ決まっていないこと

- 各回の開始時刻
- 会場（教室で合っているか）
- 持ち物
- 個別相談の予約ページのURL
- 1月16日の回のテーマ

## 3. 参加48時間後のフォロー（自動・参加した2日後）

お礼と、個別相談のご案内です。
押しつけにならないよう、選べる書き方にしています。

```
先日は体験会にお越しいただき、
ありがとうございました。

おうちに帰ってから、
どんなお話をされていましたか？

ComPassが大切にしているのは、
「わかる」から「好きになる」こと。
お子さまに合う学び方を、もう少しじっくり
いっしょに考えたい方には、個別相談をご用意しています。

・通常の授業体験 50分
・面談 15分

ご希望の方は、下のページからご予約ください。
【個別相談の予約ページ】

「まだ迷っている」「ここが気になる」という声も、
このLINEで気軽にお聞かせください。
```

## 4. 検討中の方への再案内（手動で送る）

体験会のあと、しばらく様子を見ている方へ。
次の体験会の日程を添えて、そっと届ける文面です。

```
こんにちは、学習塾ComPassです。
先日は体験会にご参加いただき、ありがとうございました。

この先の体験会の日程をお知らせします。

・12月12日（土）速読解・計測会
・1月16日（土）【テーマ】
・3月6日（土）そろばん教室
・3月20日（土）英語教室

各回とも定員4組です。
気になる回があれば、下のページからどうぞ。
【体験会の予約ページ】

もちろん、ご質問だけでも大歓迎です。
```

送る日に合わせて、すでに終わった回は消してください。

## 5. あいさつメッセージ（友だち追加した直後）

今ジュクマで送っている文面を、まず確認してください。
そちらを引き継ぐのがいちばん安全です。
新しく作る場合の案を置いておきます。

```
学習塾ComPassです。
友だち追加ありがとうございます。

ComPassは、松山市来住町の学習塾です。
「わかる」から「好きになる」をいちばん大切に、
自分で考え、自分で選べる力を育てています。

下のメニューから
・体験会のご予約
・プロフィールのご登録
ができます。

ご質問は、このLINEにそのまま送ってください。
```

## 書くときに守っていること（第6節）

- テスト対策・点数を打ち出さない
- 管理型・詰め込み型を思わせる言葉を使わない
- 指導者の資格や経験に触れない
- そろばんやパソコンなどの道具を前に出さない
- かきかた教室、中学生向け速読解講座は出さない
