# 体験会の集客導線（2027年度・小学生向け）

申込から入会までの仕組みづくりの記録です。
決まったこと、まだ決まっていないことをここにまとめます。

## 決まったこと

- ジュクマは解約する方向（使っているのはステータス機能のみ）
- LINE拡張ツールは、プロラインフリーを第一候補として検証中
- プロラインにする場合、予約・フォーム・LINE配信はプロラインの中で完結させる
  （利用規約 第13条2項「類似システムの作成禁止」に配慮）
- 週1回、予約一覧をExcelで書き出す（バックアップと週次集計を兼ねる）

## プロラインで確認できたこと

| 項目 | 結果 |
|---|---|
| 予約カレンダー | 作れる |
| 1枠あたりの定員 | 設定できる（4組に設定予定） |
| 満席の表示 | 「満」または「×」を選べる（「満」を推奨） |
| 予約直後の自動メッセージ | 届く |
| 予約の変更・キャンセル | 保護者側でできる |
| 予約時の追加質問 | 登録フォームをつなげられる |
| 予約一覧 | 検索・カレンダー別の絞り込み・ノート欄あり |
| 書き出し | CSV・Excel（カレンダーを1つ選ぶとフォーム回答も出る） |
| 電話での申込 | 手動で登録できる |
| 自己登録・ステータス変更 | フォームとシナリオ移動つきアンケートで代替できそう |
| 運営会社 | データマーケティング株式会社（東京都渋谷区） |

## まだ確認できていないこと

- データの保存場所（国）
- 保護者さんのデータを別目的に使わないか
- 解約時のデータ削除の時期
- 保護者さんの画面に広告が出るか（利用規約 第10条）
- ステータスの選択肢を変えられるか
- 91日目以降もフリーで予約・フォームが使えるか
- 管理者へのメール通知、申込者へのメール控え
