# コッピー｜ComPassキャラクターデザインシステム

子どもの一歩を、となりで見守る小さな羅針鳥。
やさしく寄り添いながら、「できた！」「やってみよう！」をそっと後押しする存在。

原本の画像は `assets/reference/` にある。迷ったら必ず画像を開いて確認する。

- `design-system.png`：デザインシステム全体（1〜12章）
- `three-views-emotions.png`：三面図と喜怒哀楽のバリエーション

## 1. 基本設定

| 項目 | 内容 |
|---|---|
| 名前 | コッピー |
| 役割 | 学習塾ComPassの案内役。子どもたちに寄り添い、学びの方向をやさしく示す存在 |
| キャラクター種別 | 鳥のキャラクター |
| 印象キーワード | やさしい／ゆるい／親しみやすい／ちょっと天然／安心感がある／子どもに近い目線／見守る存在 |

## 2. 基本フォルムと比率

- 頭は小さめの丸。頭のてっぺんに、丸いしずく形の冠羽（とさか）が1つ
- 胴体は大きな洋なし形（下ぶくれ）。頭と胴体は首でゆるくくびれる
- 羽は左右に1枚ずつ。羽の中に短い点線（羽の模様）が並ぶ
- 足は細い2本線。先は3本指
- 比率の目安：頭 約25%／胴体 約55%／足 約15%／羽飾り 約5%
- 三面図
  - 正面：くちばしは顔の中央。片方の羽を上げ、片方を腰に当てる
  - 側面：くちばしが横に出る。羽は胴体の中央に楕円で見える
  - 背面：顔のパーツはなし。羽と冠羽だけ

## 3. 線のルール

- やさしいブルーの手描き風の線
- 太さはやや太めで、揺れのある線にする
- 角はつくらず、すべて丸く
- 線端は丸く処理する
- 黒い太線にはしない（11章のNG）。ただし、まわりに合わせた黒の細い手描き線は使ってよい（線画PNGの節）

## 4. カラーパレット

メインカラー

| 色 | コード | 使う場所 |
|---|---|---|
| やさしいブルー | #6F96D1 | 線・くちばし・冠羽・目 |
| ホワイト | #FFFFFF | 体の中 |
| ごく薄い水色グレー | #EEF4F8 | 背景 |
| あたたかいオレンジ | #E89A5A | アクセント |

サブカラー（感情や装飾にだけ使う）

| 色 | コード |
|---|---|
| 明るい黄色 | #F6C85F |
| 赤みオレンジ | #E86D5A |
| 淡い水色 | #9FC7E8 |
| ピンク | #F4A6B8 |

- 原色を多用しない
- ほっぺのピンク、汗や涙の水色、怒りマークの赤みオレンジ、音符のピンクなど、感情の記号に使う

## 5. 顔のルール

- 目：小さな点。青系。表情によって、点・閉じ目・半目に変える
- くちばし：横長の丸い形。青で塗る。大きすぎず、顔の中心に置く
- 表情の基本は、やさしく、ゆるい表情
- 基本の4つ：ふつう／にっこり／まばたき／びっくり

## 6. 喜怒哀楽の表情ルール

| 感情 | 描き方 | 使用場面 |
|---|---|---|
| 喜（うれしい） | 目を閉じる、または上向き。羽を上げ、体を弾ませる。キラキラや線を入れる。ほっぺにピンク | できた！／正解！／よくがんばったね。成績アップ・合格・達成報告など |
| 怒（ぷんぷん） | 目を吊り目にする。怒りマークを入れる。羽を腰に当てる、または片羽を上げる（怖くしすぎない） | 勉強法の注意喚起／やる気アップのきっかけ。スマホ時間の見直し／注意喚起など |
| 哀（しょんぼり） | 目を下げる。羽を下げ、体を丸める。涙は1粒程度まで | テストで思うようにいかなかったとき。やり方がわからないとき／相談したいとき |
| 楽（わくわく） | 目をキラッとさせる、またはにっこり。片足を上げる、羽を広げる。音符や星を入れる | イベント告知／楽しい学びの紹介。講習・実験・読書感想文教室など |

## 7. 基本ポーズバリエーション

1. 正面立ち
2. 案内する（片羽で方向を示す）
3. 喜ぶ
4. 歩く（足あとをつけてもよい）
5. しょんぼり座る
6. ノートを持つ
7. 鉛筆を持つ
8. 吹き出しで話す

NGポーズ

- 鋭い目つき
- 人間らしすぎる動き
- かっこよすぎる決めポーズ
- 複雑な動きや色数の多い衣装

## 8. 吹き出しルール

- 丸みのある吹き出し
- 線はコッピーと同じブルー
- 背景は白または薄い水色
- 文字は黒または濃いネイビー
- 1〜2行、20字程度まで
- 子どもにも読める言葉にする
- やさしく前向きなトーンで

例：「ここ、見てみよう」「できたところもあるよ」「まず1つ、やってみよう」「大丈夫、少しずつ進もう」

## 9. キャラクターの口調

- 一人称：基本は使わない。使う場合は「ぼく」
- 話し方：やさしい／短い／子どもにも伝わる／ほんの少しだけ先生っぽい
- 例文
  - ここ、見てみよう
  - できたところもあるよ
  - まちがいはチャンスだよ
  - 次の一歩を考えよう
  - 大丈夫。少しずつ進もう

## 10. 使用シーン別の役割と使い方

| 媒体 | 役割 | セリフの例 |
|---|---|---|
| Instagram投稿 | 目を引くワンポイント。説明の補足役。最後にCTA（行動のお願い）へ誘導 | 「まずはここから見直そう」「続きは保存して見返してね」 |
| チラシ・ポスター | タイトル横の案内役。特典や注意の案内。QRコードへの誘導 | 「体験で待ってるよ！」「ここから申し込めるよ」 |
| 教材・プリント | ポイントや注意の案内。がんばりを認める役。振り返りのサポート | 「ここがポイント！」「次はここにチャレンジ！」 |

## 11. デザイン上の禁止事項

- 黒い太線にする
- 原色を多用する
- リアルな鳥に寄せる
- 表情を激しくしすぎる
- 派手な服を着せる
- 頭身を高くする
- 目を大きくキラキラさせすぎる
- ゆるさを消して整えすぎる

## 12. ComPassのブランドとのつながり

コッピーは、学びの道をいっしょに見つける小さな案内役。
「失敗OK」「まずやってみよう」「子どもの可能性を信じる」というComPassの想いを、やさしく伝える。

特に相性がよいテーマ：小学生向け講座／コンパスキッズ／読書感想文教室／夏の学習会／勉強習慣づくり／保護者向けの解説／失敗OKのメッセージ

羅針盤（コンパス）のモチーフと一緒に置くと、ブランドとつながりやすい。

## すぐ使える線画（PNG・背景透明）

| ファイル | ポーズ | 合う場面 |
|---|---|---|
| `bird-wave.png` | 片羽を上げる（正面立ち・あいさつ） | 呼びかけ、ゴール、注意喚起のやわらかい入口 |
| `bird-walk.png` | 歩く＋足あと | 計画・ルート・「一歩ずつ」 |
| `bird-study.png` | ハチマキで机に向かう | 勉強中、ワーク、テスト前 |
| `bird-pair.png` | 2羽ならぶ | 友だち、親子、なかま |

- `assets/line-blue/`：線をやさしいブルー #6F96D1 にしたもの
- `assets/line-black/`：元の黒線

線の色は、まわりのイラストに合わせて決める（2026-10-23 Nahoが決定）。

- モノクロ印刷：黒線
- カラーでも、アイコンや図などほかのイラストが黒線の紙：黒線にそろえる。ブルーだけ浮いて違和感が出るため
  （例：test-guide の「テスト前の羅針盤」「21日間ルートマップ」は黒線）
- まわりも青系の線で描くとき、キャラクターが主役の紙、Instagramなど：ブルー線
- 迷ったら、黒線とブルー線のどちらにするかNahoに聞く
- 色を変えたいときは `python3 scripts/recolor.py 入力.png 出力.png #色コード`
- ComPassのロゴは `assets/compass-logo.png`

これらは、ハチマキなど三面図にない要素が入った初期の線画。
新しく描くときや画像を生成するときは、三面図（`three-views-emotions.png`）を正とする。

## 制作物に入れるときのチェック

- [ ] 線の色が、まわりのイラストとそろっている（上の「線の色」のルール）
- [ ] 頭身が低く、丸いフォルムのまま
- [ ] 表情は「やさしい・ゆるい」の範囲。怒りも怖くしすぎていない
- [ ] サブカラーは感情の記号だけに使っている
- [ ] 吹き出しは20字程度まで。子どもが読める言葉
- [ ] 一人称を使うなら「ぼく」
- [ ] 媒体ごとの役割（10章）に合っている
