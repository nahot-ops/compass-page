# レポート形式

保存先: Googleドライブ「伸び投稿レポート/02_毎朝のレポート」にGoogleドキュメントで作る（手順はSKILL.md）
太字（**）は使わない。

---

```markdown
# 伸び投稿レポート YYYY-MM-DD（曜）

データ: バイラルファインダー（◯月◯日抽出）
チェック数: ◯件 → 伸び投稿 ◯件 → 使える投稿 ◯件

## 今日のトップ3

1. 【S／保存型】テーマ一言 → 使うならジャンル◯◯
2. 【A／DM型】テーマ一言 → 使うならジャンル◯◯
3. 【A／シェア型】テーマ一言 → 使うならジャンル◯◯

---

## 1. テーマ一言

アカウント: @xxxx（フォロワー◯万）
形式: リール 30秒 / カルーセル8枚 など
URL: https://...
ランク: S（保存型）
数字: いいね◯ ／ 保存率◯% ／ シェア率◯% ／ DM率◯% ／ 倍率◯倍
（推定の場合はここに「推定：保存・シェア欠損」と書く）

適合ジャンル: 09 親の声かけ（3）、10 やる気（2）

### テーマ
この投稿が何を伝えているかを1〜2行で。

### なぜ伸びたか
- フック: 1枚目／冒頭で何を言ったか
- 突出した数字: 例）保存率62%。手順が7つ並んでいて見返したくなる
- 感情: 例）「うちの子もそう」という共感

### 使える切り口3つ
1. 塾講師視点
   フック案: 「テスト前に"頑張れ"は逆効果でした」
   中身: 現場で見た具体例 → 代わりの声かけ3つ
2. 保護者視点
   フック案: 「〜〜」
   中身: 〜〜
3. 方眼ノート視点
   フック案: 「〜〜」
   中身: 〜〜

---

（2件目以降も同じ形式。最大10件）

## 型だけ借りる枠（適合度1）

- @xxxx「テーマ」……借りられるのは◯◯の構成
- ...

## 今日のひとこと

全体を見て気づいた傾向を2〜3行。
例）今週は「親のNGワード系」の保存率がずっと高い。
　　僕らも声かけシリーズを週1で回すと良さそう。
```

---

