# 「伸び投稿」の定義

## 前提：データは手動で集める

投稿はNahoがスマホで見て「伸びてる」と思ったもの。
他人の投稿の保存数・シェア数・DM数は、ふつう画面に出ない。
なので実際には、主に「いいね・コメント・再生数・フォロワー数」で判定する。
下の保存率などの基準は、数字が分かったときだけ使う。

### 手動データでのランク（こちらを優先）

- 反応率 = いいね数（リールは再生数）÷ フォロワー数
- S ……反応率 20%以上（リール再生は 300%以上）
- A ……反応率 10%以上（リール再生は 150%以上）
- B ……反応率 5%以上（リール再生は 80%以上）
- 参考 ……それ未満、またはフォロワー数が分からない

コメント率（コメント÷いいね）が 5%以上なら、1段上げる。
（共感や質問が集まっている＝保存・シェアも多い可能性が高い）

フォロワー数が分からない投稿は「参考」にして、
レポートに「プロフィールのスクショがあれば判定できます」と添える。

---

以下は、保存・シェア・DMの数字が手に入ったときの詳しい基準。

フォロワー数が違うアカウントを公平に比べるため、
絶対数ではなく「比率」で判定する。
数値はすべて初期値。運用しながら調整する。

## 指標の計算

- 保存率 = 保存数 ÷ いいね数
- シェア率 = シェア数 ÷ いいね数
- DM率 = DM送信数 ÷ いいね数
- 伸び倍率 = その投稿のいいね数（リールは再生数）÷ そのアカウントの平均
  - 平均がデータに無ければ、同じCSV内の同アカウント投稿の中央値で代用
  - それも無ければ「いいね数 ÷ フォロワー数」が 5% 以上を倍率3倍相当とみなす

## 各指標の基準ライン

| 指標 | 基準ライン | 強い（S判定用） |
|---|---|---|
| 伸び倍率 | 3倍以上 | 10倍以上 |
| 保存率 | 30%以上 | 60%以上 |
| シェア率 | 10%以上 | 25%以上 |
| DM率 | 5%以上 | 15%以上 |

保存数・シェア数・DM数そのものにも下限を置く。
保存100 / シェア30 / DM20 未満の指標は「基準超え」に数えない。
（小さいアカウントの偶然の比率を除くため）

## ランク判定

- S ……伸び倍率が基準ライン以上、かつ
  保存率・シェア率・DM率のどれか1つが「強い」
- A ……伸び倍率が基準ライン以上、かつ
  保存率・シェア率・DM率のうち2つ以上が基準ライン以上
- B ……伸び倍率が基準ライン以上、かつ
  保存率・シェア率・DM率のどれか1つが基準ライン以上
- 参考 ……上のどれにも当たらない

投稿日から7日以上たった投稿は、ランクを1段下げる。
（古いネタはすでに出回っているため）

## 伸び方のタイプ

ランクとは別に、いちばん突出した指標で型を付ける。
「なぜ伸びたか」の分析の起点にする。

- 保存型 ……見返したい情報（手順・一覧・チェックリスト）
- シェア型 ……誰かに言いたい（あるある・意外な事実・主張）
- DM型 ……特定の誰かに送りたい（「これ〇〇じゃん」系）
- 拡散型 ……倍率だけ突出（フック・トレンド音源・炎上気味）

## 数値が欠けているとき

保存・シェア・DMは、競合の投稿だと取れないことが多い。
欠けているときは次のルールで判定する。

- 3指標とも無い → 伸び倍率 5倍以上 かつ
  コメント率（コメント÷いいね）3%以上 で B とする
- 1〜2指標だけある → ある指標だけで判定する
- レポートには必ず「推定」と書き、何が欠けていたかを残す
