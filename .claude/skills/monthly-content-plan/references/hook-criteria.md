# 損失回避／利得／意外性の判定基準

企画候補を「どの感情で読ませるか」で採点する表。
3軸それぞれを 0〜3点 で付ける。

主軸は1つに決める。
3軸すべてが高い企画は、たいてい焦点がぼやけている。

---

## 1. 損失回避（このままだと損をする）

読者が「知らないと損をする」「今やらないと手遅れ」と感じる軸。
人は得をするより、損を避ける方に強く動く。

### 判定のサイン
- 「〜していませんか？」「〜だけはやめて」で始まる
- 失うものが具体的（面談の10分、2学期の内申、毎晩の30分）
- 期限がある（面談の前、テストの2週間前）

### 点数
- 0 ……失うものが無い
- 1 ……失うものはあるが、ぼんやりしている（「成績が下がるかも」）
- 2 ……失うものが具体的で、読者が自分に当てはめられる
- 3 ……失うものが具体的で、期限があり、今日できる回避策まで付いている

### やりすぎライン（当たれば0点、企画ごと除外も検討）
- 親を責める（「親のせいで〜」）
- 他の子と比べて焦らせる
- 回避策が「入塾するしかない」だけ
- 点数・偏差値の実数で脅す
- 特性や不登校を「放っておくと危ない」と扱う

損失回避は、読んだあと安心して終われる形にする。
「失うもの」の次に、必ず「今日できる一手」を置く。

### ComPassでの例
- 「面談の10分、メモがぐちゃぐちゃで終わっていませんか？」
- 「テスト前の『頑張れ』が、逆効果になっている夜があります」

---

## 2. 利得（これをやると得をする）

読者が「これをやれば良くなる」「簡単に手に入る」と感じる軸。

### 判定のサイン
- 「〜するだけ」「〜3選」「テンプレ付き」
- 手に入るものが具体的（聞くことリスト、声かけの言い換え3つ）
- 手間が小さい（毎日10分、ノート1ページ）

### 点数
- 0 ……得るものが無い、または読むだけで終わる
- 1 ……得るものはあるが、手間が大きいか抽象的
- 2 ……得るものが具体的で、手間も小さい
- 3 ……そのまま保存して使える形（チェックリスト・テンプレ・手順）になっている

### やりすぎライン
- 結果を約束する（「これで点数が上がる」「必ず伸びる」）
- 特定の商品・教材の宣伝が主目的になる

### ComPassでの例
- 「方眼ノート1ページを3つに分けるだけ。面談メモのテンプレ」
- 「面談のあと、子どもに最初にかける一言」

---

## 3. 意外性（え、そうなの？）

読者の思い込みをひっくり返す軸。
シェア・DMにつながりやすい。

### 判定のサイン
- 「実は」「逆に」「〜しない方がいい」
- 常識と反対のことを、理由付きで言っている
- 立場があるから言える内側の話（塾の先生が本当に知りたいこと）

### 点数
- 0 ……誰でも知っている話
- 1 ……少し新しいが、驚きはない
- 2 ……思い込みと逆のことを、理由付きで言えている
- 3 ……思い込みと逆で、しかも現場の具体例があり、人に言いたくなる

### やりすぎライン
- 根拠の無い逆張り（「勉強しなくていい」だけで終わる）
- 学校・他塾・先生を悪く言って驚かせる
- 生徒が特定できるエピソードを使う

### ComPassでの例
- 「塾の先生が本気で知りたい。個人面談で聞いてきてほしいこと」
- 「点数の話が消えた子ほど、中3の冬に強くなります」（方眼ノートの記録から）

---

## 伸び方の型との相性

毎朝のレポートの「伸び方の型」と、主軸の組み合わせ。

| 伸び方の型 | 相性のいい主軸 |
|---|---|
| 保存型 | 利得（型・リストがある） |
| シェア型 | 意外性 |
| DM型 | 損失回避、意外性（「これ〇〇じゃん」） |
| 拡散型 | 意外性（フック勝負） |

## 採点表（企画候補ごとに埋める）

| 項目 | 内容 | 点 |
|---|---|---|
| NGチェック | ブランド禁止語・やりすぎライン・ジャンルのNG | 通過／除外 |
| 損失回避 | 0〜3 | |
| 利得 | 0〜3 | |
| 意外性 | 0〜3 | |
| フック点 | 主軸の点×2 ＋ 残り2軸の合計 | /15 |
| バズ因子 | 該当因子数。定番は2、傾向は1.5、仮説は1で数える | |
| 集客適合 | 0〜3（今月の募集・講座の動きと合うか） | |
| 合計 | フック点＋バズ因子＋集客適合×2 | |

主軸の点が2未満の候補は、合計が高くても主企画にしない。
読ませる感情が弱いと、どの因子を足しても伸びにくいため。
